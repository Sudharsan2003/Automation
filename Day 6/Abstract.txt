1. Explain the Difference between Abstract Class and Interface with example program

Feature                         Abstract                                 Interface

Keyword                         abstract class                           interface

Methods                         Can have both abstract and               Mainly defines the methods implementing
                                concrete method.                         classes must provide


Variables                       Can have instance variables              Variables are implicitly public, 
                                                                         static, and final.

Constructor                     Can have constructor                     Cannot have constructor

Inheritance                     A class can extend only one              A class can implement multiple interfaces
                                abstract class     
    
Usecase                         When you want to share code              When you want to define a contract 
                                among related classes                    for unrelated classes

Example Of Abstract Class:

package assignment;

abstract class Bike{
	public abstract void brand();
	
	void model() {
		System.out.println("Model: Apache RR 310");
	}
	
	public abstract void price();
}

public class Abstraction extends Bike{

	public static void main(String[] args) {
		// TODO Auto-generated method stub
		Abstraction ob = new Abstraction();
		ob.brand();
		ob.model();
		ob.price();
	}

	@Override
	public void brand() {
		// TODO Auto-generated method stub
		System.out.println("Brand: TVS");
	}

	@Override
	public void price() {
		// TODO Auto-generated method stub
		System.out.println("Price: 300000");
		
	}

}

Output:

Brand: TVS
Model: Apache RR 310
Price: 300000

Example Of Interface:

package assignment;

interface Car{
	int price=1500000;
	void brand();
	default void model() {
		System.out.println("Model: BE.07");
	}
	static void type() {
		System.out.println("Type: Electric Suv");
	}
}

public class Interface implements Car{

	public static void main(String[] args) {
		// TODO Auto-generated method stub
		Interface ob = new Interface();
		ob.brand();
		ob.model();
		Car.type();
		System.out.println("Price:" + Car.price);
		}

	@Override
	public void brand() {
		// TODO Auto-generated method stub
		System.out.println("Brand :Mahindra");
		
	}

}

Output:

Brand :Mahindra
Model: BE.07
Type: Electric Suv
Price:1500000

2.Explain about Overloading and Overriding with example programs

Method Overloading:

Method Overloading allows multiple methods with the same name but different parameters within the same class

Example:

package assignment;

class Calculators{
	int calculate(int a,int b) {
		return a+b;
	}
	int calculate(int a,int b,int c) {
		return a*b*c;
	}
	int calculate(int a,int b, int c,int d) {
		return a+b+c+d;
	}
}

public class Methodover {
	
	public static void main(String[] args) {
		// TODO Auto-generated method stub
		Calculators ob = new Calculators();
		System.out.println(ob.calculate(5, 5));
		System.out.println(ob.calculate(5,5, 5));
		System.out.println(ob.calculate(2, 4, 6, 8));

	}

}

Output:

10
125
20

Method Overriding:

Method overriding allows a subclass to provide a specific implementation of a method already defined in its parent class.

Example:

package assignment;

class Bus {
    void mtc() {
        System.out.println("What is full form of MTC?");
    }
}

public class Methodride extends Bus {

    @Override
    void mtc() {
        System.out.println("Metropolitan Transport Corporation");
    }

    public static void main(String[] args) {
        Methodride ob = new Methodride();
        ob.mtc();
    }
}

Output:

Metropolitan Transport Corporation
